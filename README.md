# Fridge
Холодильник на питоне
Программа хранит информацию о продуктах в холодильнике: что лежит, в каком количестве и до какого числа годно. 
Можно добавлять новые продукты, искать их по названию и узнавать, сколько чего осталось

Все продукты лежат в одном словаре goods. Ключ это название продукта, а значение это список партий этого продукта.
Партия появляется каждый раз, когда продукт покупают. Например, если сначала купили 10 яиц, а через неделю ещё 3, у яиц будет две партии со своими сроками годности. Для каждой партии хранятся два значения: количество и срок годности. Количество записывается числом типа Decimal: целым для штучных товаров и дробным для весовых. Если срок годности неизвестен, вместо даты хранится None.

Функции

add добавляет партию продукта. Ей передают словарь с продуктами, название, количество и, если нужно, срок годности строкой в формате «год-месяц-день». Если такого продукта в холодильнике ещё нет, функция создаёт для него новую запись, а если есть, добавляет новую партию к уже существующим. Ничего не возвращает.

add_by_note делает то же самое, но принимает продукт одной строкой в виде «название количество срок годности», например «Яйца гусиные 4 2023-07-15». Срок годности можно не указывать. Функция сама разбирает строку на название, количество и дату и передаёт их в add. Название может состоять из нескольких слов. Тоже ничего не возвращает.

find ищет продукты по части названия, не обращая внимания на заглавные и строчные буквы. Возвращает список названий, в которых встретилась искомая строка. Если ничего не нашлось, возвращает пустой список.

amount считает, сколько всего есть нужного продукта. Сначала находит подходящие названия через find, затем складывает количество по всем их партиям. Возвращает число типа Decimal. Если такого продукта нет, получится ноль.

В конце файла находятся тесты: в них продукты добавляются с вчерашней, завтрашней и отдалённой датой, с указанием срока годности и без него, а также повторно добавляются уже существующие продукты. Затем проверяются поиск и подсчёт количества, в том числе для продукта, которого в холодильнике нет. Вспомогательные функции для красивого вывода нужны только для тестов и в основную логику не входят.
